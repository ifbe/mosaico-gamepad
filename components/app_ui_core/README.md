# app_ui

Bezel marquee UI: a black 480x480 screen with a light chasing the four edges.

## Responsibilities

- Owns the GSP scene (`ui/main.json`): black background, four dim edge lines and
  36 hidden orange dots placed around the perimeter.
- Advances a 3-dot tail every 70 ms with a GSP timer (UI task context).

## Dependencies

- `esp-gsp` (scene bundle generated by gspc at build time).

## Minimal usage

```c
ESP_ERROR_CHECK(app_ui_start(ui_handle)); /* after esp_gsp_esp_lcd_start() */
```

Call once; the timer runs until reboot.
